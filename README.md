## 当前状态：页面不标价

按你的要求，**全站没有任何具体价格数字**。

客户在工作台选类型、勾需要的端、写想法，点「生成需求清单」后会看到：

- 预计工期（15–30 个工作日，按类型给）
- 报价方式：**按功能清单评估后报价**
- 包含什么（前端 / 后端 / 管理后台 / 源码 / 部署文档）
- 一句「分阶段付款：确认后付定金开工，验收通过再付尾款」

然后点「把这个需求发给工程师」→ 填联系方式（**手机号或微信号至少留一个**）→ 提交后：

1. **自动推送到你的企业微信群机器人**（地址在 `index.html` 的 `window.JY.webhookParts`，分段存放）
2. 页面上给客户显示格式化需求单 + 一键复制 + 你的微信二维码

推送消息里**联系方式排在最前面**，你一眼就能看到客户的手机号/微信号，直接回过去。

**以后要标价的话**：改 `index.html` 里每个 chip 的 `data-name`，给需要的档位加 `data-base`（基准价）、`data-deposit`（定金），再在 `main.js` 的 `renderSummary()` 里把「报价方式」那行换成价格行即可。

## 需求推送：为什么不能直连，怎么接

**硬限制（已实测）**：企业微信群机器人 **不允许浏览器直连**。从网页 POST 过去会拿到：

```
HTTP 403 + CORS 拦截（net::ERR_FAILED）
```

企微的设计就是"只给服务器调用"。所以纯静态站想自动推送，中间必须有一个中转。

### 三个可选方案（每个都只需你做一步）

| 方案 | 你要做什么 | 到达速度 | 前置条件 |
|---|---|---|---|
| **A. PushPlus / Server酱 微信推送** | 微信扫一次码，把 token 发我 | 秒到微信 | 无 |
| **B. Cloudflare Worker 中转** | 注册 CF，把我写好的 6 行代码粘进去 | 秒到企微群 | 需 CF 账号（免费）|
| **C. 邮件直达（FormSubmit）** | 点一次邮箱里的确认链接 | 1 分钟内到邮箱 | 无 |
| **D. 暂不接** | 什么都不用做 | 客户复制后加你微信 | 无 |

拿到结果后，填到 `index.html` 里这一行即可，全站生效：

```js
pushUrl: "",   // ← 中转地址填这里
```

前端会 POST 过去一个 JSON：`{text, phone, wechat, name, kind, direction}`
`text` 是完整需求单文本，`phone` / `wechat` 单独也给你一份，方便直接拨号或加好友。

## 改完必测清单（每次动完网站都跑一遍）

> 起因：做视觉美化时加了一行 `header, main, footer, .modal-mask { position: relative; z-index: 1; }`，
> 顺手把弹窗的 `position: fixed` 和 `z-index: 300` 覆盖掉了 —— 结果客户点「发给工程师」后
> **页面滚动被锁死、弹窗掉到页面最底部看不见**，表现为"整页卡住"。
> 这类 bug 光看截图发现不了，必须真机点一遍。

### 一、手机上真机走一遍完整流程（最重要）

用手机打开线上地址，依次点：

1. 选「做一个小程序 / 一个网站 / 一个系统」三个 tab —— 面板能切换
2. 点一个方向标签、多选几个「需要的端」—— 标签能选中
3. 点「生成需求清单」—— 清单出现在按钮下方
4. 点「把这个需求发给工程师」—— **弹窗必须铺满屏幕、能填字、能关掉**
5. 联系方式留空直接提交 —— 必须弹提示拦住
6. 填好提交 —— 出需求单 + 二维码
7. 点「一键复制」—— 按钮变「已复制 ✓」
8. 关掉弹窗 —— **页面能继续上下滚动**（不能卡住）
9. 悬停/点开案例页的卡片、参考页的卡片 —— 能打开原站
10. 点「案例参照」页的搜索、翻页 —— 能筛能翻

### 二、拿开发者工具跑这几项（或者照上面的现象看）

| 检查 | 合格标准 |
|---|---|
| 弹窗定位 | `getComputedStyle(弹窗).position` = `fixed`，`zIndex` = `300` |
| 弹窗尺寸 | 铺满视口（和屏幕同宽同高） |
| 屏幕中心最上层元素 | 是弹窗里的输入框，不是页面内容 |
| 关闭后 `body.style.overflow` | 变回空字符串（滚动恢复） |
| 控制台 | 0 个 JS 报错 |
| 横向溢出 | 390 / 480 / 768 / 1024 / 1440 五档宽度 × 6 个页面，全部 `scrollWidth == clientWidth` |

### 三、改动视觉/特效时额外注意

叠加纹理、光晕、动画这类装饰层，**最容易踩的两个坑**：

1. **层级被覆盖**：写 `position` / `z-index` 的批量选择器时，别把 `.modal-mask`、`.ref-lightbox` 这类浮层一起带进去
2. **溢出**：装饰层超出视口会产生横向滚动条。用 `main { overflow-x: clip; }`（只裁横向，不影响纵向）
